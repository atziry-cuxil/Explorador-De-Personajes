# Explorador de Personajes
## Pokédex

Es un proyecto de tipo Pokédex que permite explorar diferentes Pokémon de forma sencilla e interactiva. Los Pokémon se muestran mediante páginas y el usuario puede filtrarlos, consultar sus detalles y agregarlos a una lista de favoritos.

✨ Características
- Visualización de diferentes Pokémon.
- Páginas para explorar los Pokémon.
- Filtro de búsqueda de Pokémon dentro de la página actual.
- Posibilidad de agregar Pokémon a favoritos.
- Visualización de información detallada de cada Pokémon.

🛠️ Tecnologías

- HTML
- CSS
- JavaScript
- React
- React bootstrap

📖 Uso

El usuario puede:

- Navegar entre las diferentes páginas.
- Utilizar el filtro para buscar un Pokémon dentro de la página actual.
- Seleccionar un Pokémon para consultar sus detalles.
- Agregar Pokémon a favoritos mediante el botón correspondiente.
- Consultar los Pokémon agregados a favoritos.

El objetivo del proyecto es permitir que el usuario pueda explorar, buscar y consultar información de diferentes Pokémon. 

Incorporamos funcionalidades de paginación, filtrado, favoritos y visualización de detalles.
